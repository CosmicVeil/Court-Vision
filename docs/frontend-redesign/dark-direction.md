# Dark redesign direction

Generate a new CourtVision web UI using the existing screen brief and archive images for content, data and controls. Use charcoal graphite, neutral raised surfaces, bright gray-white text, and controlled CourtVision orange. Use concise sentence-case labels, strong alignment and tabular figures. The date, matchup choices and players should lead the visual hierarchy.

Sleeper reference principles are compact player identity and readable stat comparisons. TheScore reference principles are a compact matchup strip, strong live and schedule context, and glanceable numbers. Use distinct CourtVision branding and layout.

Apple informs motion. The matchup selection indicator slides into place and player results crossfade in place. Filter menus and the player sheet move from their trigger. Preserve the header and scroll position where appropriate. Use short easing and a reduced-motion version with immediate state changes. Annotate these separately from the static screenshots.

Start with the signed-in desktop and mobile Next-Game Predictions screens. The complete state inventory is in the mockup checklist.
