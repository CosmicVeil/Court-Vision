## Existing UI brief

- Title, summary, last-updated date and developer-authored disclaimer. Visible content includes Cookies, browser storage (authToken, user and nba_favorites), account/database storage and session timing, Third parties (Google Fonts, hosting, public NBA sources and LinkedIn), data use commitments, Your choices and Changes. The published text links to Contact for account deletion requests. Footer has brand and Contact. Content appears as a single reading sequence on desktop and phone.
